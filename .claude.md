

Chess tournament prep web app. User enters an opponent's name, the app scouts them and returns a report that helps the user win. Reference: https://players.chessbase.com

Aussume users are lazy, and want mazimun intel with minimum navigation. Aussume user's not want to be in this website. 
## Core Flow
1. Match name to FIDE ID, Chess.com ID, Lichess IDj (disambiguate duplicates)
2. Collect public games (Chess.com API, Lichess API, PGN databases)
3. Compute win/loss/draw rates as White and as Black
4. Identify most likely openings, favorite lines, and playing style
5. Show a scouting report with prep tips

## Design Principles
- Easy to use without instructions
- Clean design, smooth animations, readable charts

## Rules
- Handle missing data gracefully, never show broken or empty pages
- Never invent stats, only compute from real game data
- Plain vocabulary and short sentences
- Warm and human tone, not formal
- No em dashes and no semicolons
